## Suite truth guard

`run-guarded.mjs` wraps Playwright, reads the JSON report and exits non-zero when **only skipped tests** ran (0 passed, 0 failed, skipped > 0) unless `E2E_ALLOW_ALL_SKIPS=1`. Use `npm run e2e:guarded -- --project=chrome`. This prevents a green run that executed nothing. Verified with `npx playwright test specs/ws-contract.spec.ts --project=chrome` (all app-bound tests skip -> exit 1) and with the full run (passes present -> exit 0).
