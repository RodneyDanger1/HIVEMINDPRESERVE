# 1.1 Wave 1 — recovery / residual repair plan

Status: implementation plan (executed after this file is written). Scope: the concrete residuals left by the 1.0 release and the 8-seat/4-planner reports.

## Outcome

`NODE_REWIRE` events carry the task's real current lifecycle state, the web refusal vocabulary covers all 65 backend codes with a drift test, and every tool/CLI child process receives a minimal allowlisted environment instead of inheriting the parent process environment. The audit paper records that A-F01/A-F02/A-F03 were fixed after the audit snapshot.

## Current behavior (evidence)

- `ws.rs:344` uses `AgentStateForEvent::running()` for `NODE_REWIRE`; the graph already stores the real state (`graph.rs:18-27`). S2-F-S2-02/P2.
- `web/src/api/contract.ts:332-380` has 45 codes; `refusal.rs` defines 65 real codes (+1 test-only `E_NOT_A_REAL_CODE`). S2-F-S2-01/P2.
- `shell.rs:201-208` and `cli_support.rs:41-46` inherit the parent environment; only `DEEPSEEK_API_KEY` is removed. S6-F-01/P1.
- `audit/HIVEMIND-AUDIT-PAPER.md:104,208` still describe provider/replay/parity as broken; fixed at `6a2b1c6`. S1/S8/P4.

## Decisions

1. Add a read-only `GraphAuthority::state_of` accessor; after a successful rewire, read and publish the actual state. If the node cannot be found, publish a named error; never invent `Running`.
2. Generate the TS refusal list from the Rust source as a static, sorted list; add a vitest parity test against `refusal.rs`, excluding the explicit test-only code. No runtime code generation.
3. Replace key-only removal with `env_clear` plus an explicit allowlist (`PATH`, `PATHEXT`, `SystemRoot`, `WINDIR`, `TEMP`, `TMP`, `USERPROFILE`, `HOME`, `COMSPEC`, `OS`, `PROCESSOR_ARCHITECTURE`, `NUMBER_OF_PROCESSORS`). This is a security improvement; child tools lose unrelated env, which is intentional.
4. Add a dated supersession block to the audit paper; do not rewrite the historical findings.

## Failure modes

- Rewire succeeds but state read fails: publish named `E_INTERNAL_ERROR`, do not fabricate; mutation remains truthful because the graph is authoritative.
- Refusal drift: test fails loudly when either side changes.
- Child process cannot find a required Windows variable: allowlist includes the minimal set; tests exercise `cmd`, `node`, `rustc` probes.
- Child lacks a non-allowlisted variable: intentional; canary asserts the secret is gone.

## Tests

- `cargo test --workspace --locked`; include `state_of` and child-env tests.
- `npm test -- --run` includes `refusalParity.test.ts`; typecheck/build.
- Manual `cmd /C echo %DEEPSEEK_API_KEY%` canary remains green.
- No live provider call is required for this wave.

## Rollback

Revert the wave commit. No schema/data migration; environment sanitizer can be reverted independently. The 1.0 tag remains untouched.

## Out of scope

True SSE streaming (W3), browser replay e2e (W4), tool-call loop (W10), 12 G-UI skips, full trace ladder, release re-tag (until wave verification).
